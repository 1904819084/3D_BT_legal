# Benchmark

This directory contains the public ICCAD 2022 CAD Contest Problem B benchmark cases used as a starting point for reproducing the NGLIC paper workflow.

Source repository:

```text
https://github.com/coherent17/2022-ICCAD-Problem-B
```

Files copied from the source repository's `Benchmark/` directory:

```text
case1.txt
case2.txt
case3.txt
case4.txt
```

Note: the NGLIC paper reports experiments on datasets derived from ICCAD 2022 Problem B using partitioning strategies named RND, FM, and KHP. These public case files are the base contest benchmarks, not the paper authors' generated RND/FM/KHP connection datasets.
